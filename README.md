# Rosetta-Soil

## About

Rosetta-Soil is a compact reference-data repository for soil hydraulic
parameters derived from USDA ARS Rosetta documentation. It provides the
parameter tables in spreadsheet, CSV, and JSON forms for easier use in
hydrologic and environmental-modeling workflows.

## Contents

- `rosetta_hydraulic_parameters.ods`: editable source table;
- `rosetta_hydraulic_parameters.csv`: portable tabular form;
- `rosetta_hydraulic_parameters.json`: structured parameter data;
- `converted_rosetta_hydraulic_parameters*.json`: converted variants; and
- the bundled PDF files: source and reference documentation.

## Use and provenance

Check the parameter definitions, units, transformations, soil-class mapping,
and source PDF before importing a converted file into a model. Preserve the
source attribution when redistributing or publishing derived datasets.

## Status

The files are reference conversions, not a replacement for site-specific soil
measurements or calibrated hydraulic properties.
